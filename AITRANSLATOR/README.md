# AI SignBridge: Two-Way Sign Language Translation System

AI SignBridge is a Flask-based hackathon demo for two-way sign-language translation. It combines TensorFlow CNN inference, temporal video inference, OpenCV webcam/video processing, MediaPipe hand tracking, text-to-sign video lookup, speech output, multilingual translations, Chart.js dashboards, and SQLite history.

## Features

- Real-time webcam sign detection with stable prediction voting
- MediaPipe hand tracking and hand-region crop before CNN inference
- Sign language to text and browser voice output
- Text to sign real-motion video conversion when a video dataset is collected
- Upload image and video prediction
- Confidence scores for live, image, and video predictions
- Responsive dark dashboard UI with sidebar navigation and animations
- Accuracy/loss and class-distribution charts using Chart.js
- Available signs gallery with search
- Hindi, Telugu, and Kannada translation display
- SQLite prediction history
- Training script that generates `sign_language_model/model.keras`, `sign_language_model.h5`, labels, and dashboard metrics
- WLASL subset collector for real movement videos of the available signs
- Temporal video model training script for real sign-motion prediction


## Run the App

```powershell
python app.py
```

Open `http://127.0.0.1:5000` in your browser. Allow camera access if the browser asks.

## Collect Real Motion Videos

Download WLASL processed videos from the official/GitHub/Kaggle source after accepting the dataset terms. WLASL is for academic/computational use and is not for commercial use.

Then collect only the signs used by this app:

```powershell
py collect_wlasl_subset.py --metadata C:\path\to\WLASL_v0.3.json --videos-dir C:\path\to\videos --max-per-sign 25
```

This creates:

```text
static/real_sign_videos/
  again/
  agree/
  ...
```

Train the temporal movement model:

```powershell
py train_video_sign_language.py --epochs 15
```

After training, uploaded video prediction uses `video_sign_language_model/model.keras`. Text-to-sign also prefers real motion videos from `static/real_sign_videos`.

Full training:

```powershell
python train_sign_language.py --epochs 20
```

Fast demo training:

```powershell
python train_sign_language.py --epochs 5 --max-per-class 25
```

The training script saves:

- `sign_language_model/model.keras`
- `sign_language_model.h5`
- `sign_language_model/labels.txt`
- `sign_language_model/training_metrics.json`

## Notes

- The browser uses the Web Speech API for voice output.
- Video upload prediction samples frames instead of processing every frame, keeping demos responsive.
- The app still runs if MediaPipe is unavailable, but hand tracking will be disabled.
